# WinOptimizer 0.7 Beta — Performance Center

**Предварительная версия центра мониторинга и анализа производительности Windows 10/11.**

- [Скачать WinOptimizer 0.7.7a Beta](https://github.com/reikidod/WinOptimazer/releases/tag/v0.7.7a-beta)
- [План разработки 0.7](ROADMAP-0.7.md)
- [Обратная связь и ошибки](https://github.com/reikidod/WinOptimazer/issues/9)

> [!WARNING]
> Это тестовая версия. Мониторинг и рекомендации не должны автоматически изменять параметры Windows. Любое системное действие требует отдельного подтверждения пользователя.

## Уже доступно в 0.7 Beta

- Компактная история последних 60 замеров CPU и RAM в рамках текущего сеанса.
- Текущая сетевая скорость по дельте счётчиков адаптеров.
- Мониторинг активных процессов: CPU, память, группировка одноимённых процессов и список недавно завершившихся.
- Существующие сведения о системе и доступных температурных датчиках.
- Три профиля оптимизации и Fluent-индикатор без стрелки, унаследованные из предыдущей беты.

## Что будет доведено в ветке 0.7

Разработка идёт этапами по [дорожной карте](ROADMAP-0.7.md): полноценные метрики GPU и дисковой активности, расширенная история, анализ причин нагрузки, объяснимые рекомендации, сравнение до/после, затем регрессионные проверки и финальная стабилизация.

## Правила безопасности

1. Сначала наблюдение и диагностика — никаких скрытых изменений системы.
2. Рекомендация объясняет причину, ожидаемый эффект, риски и способ отмены.
3. Применение системного изменения — только после отдельного явного подтверждения.
4. Планировщик задач остаётся только для чтения.
5. Данные мониторинга остаются локальными; перед добавлением постоянного хранения устанавливаются лимиты и политика очистки.
