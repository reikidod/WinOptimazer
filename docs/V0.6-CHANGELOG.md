# WinOptimizer 0.6.0 Beta — changelog (in progress)

## Design (old + new)
- New theme id **`fluent`** (Windows 11 slate + blue accent) is the default.
- Previous **`dark`** palette kept as **«Классическая тёмная»** in theme picker (`ThemeManager`).
- Other themes (light, midnight, emerald, …) unchanged.

## Dashboard & navigation
- `AppPage.Home` + `DashboardViewModel` + `Views/DashboardPage.xaml`.
- Metrics: CPU %, RAM, optional CPU/GPU temps via existing `TemperatureReader`.
- Monitoring runs **only while Home is active** (`SystemMonitorService`).
- Built-in optimization profiles: gaming / daily / power-save (`OptimizationProfileService`).
- Recent operations list (`OperationHistoryService`).

## Safety
- `RiskLevel` Low/Medium/High derived from tweak Warning + RequiresReboot (shown in HelpTip).
- Operation history written on tweak apply and restore points.

## Version
- `WinOptimizer.csproj` → **0.6.0**.
