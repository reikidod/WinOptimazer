# Безопасность

## Сообщить об уязвимости

Если нашли уязвимость в WinOptimizer — **не создавайте публичный Issue**.

Напишите автору репозитория через GitHub (Security advisory или личное сообщение владельцу `reikidod`) и кратко опишите:

- версию приложения;
- шаги воспроизведения;
- возможное влияние.

Мы постараемся ответить в разумные сроки.

## Что уже заложено в дизайн

- откат изменений реестра;
- проверка SHA-256 для рекомендуемых файлов;
- отсутствие телеметрии;
- открытый исходный код и сборка через GitHub Actions.

## SmartScreen и антивирусы

Предупреждения Windows SmartScreen для неподписанных или малоизвестных сборок — ожидаемое поведение. Исходники и CI-релизы можно сверить с GitHub.
