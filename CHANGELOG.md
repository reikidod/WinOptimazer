# История изменений

## 0.6.149 Beta — подготовлено

### Новое
- Планировщик задач Windows в режиме read-only: чтение вложенных папок и скрытых заданий, поиск по названию, пути, автору и описанию.
- Категории задач: системные, драйверные и пользовательские; фильтры по состоянию и категории.
- Подробности задач: автор/издатель, описание, время последнего и следующего запуска, код последнего результата в hexadecimal.
- Явная маркировка NVIDIA-температур как GPU-сенсоров.

### Улучшения
- Поиск планировщика разбивает запрос на слова и учитывает название, путь, автора и описание.
- Dashboard сериализует сбор системных показателей; инициализация PerformanceCounter защищена от гонки с ручным обновлением.
- Сводка планировщика показывает количество отображаемых задач относительно общего числа.

### Безопасность
- Планировщик задач не запускает, не останавливает, не включает и не отключает задания.
- Диагностика и чтение температур не меняют системные настройки.

### Проверки
- Windows Release build.
- 183 автоматических теста.
- Проверка установщика: тихая установка и удаление.
- Smoke test запуска приложения.

## 0.6.104 Beta — первоначальный релиз

### Новое
- Главная панель с быстрым снимком состояния CPU, RAM, системного диска и сети.
- Диагностика Windows: свободное место, загрузка памяти, сетевое подключение, права запуска и признаки ожидающей перезагрузки.
- Локальная история действий для оптимизации, очистки и диагностики.
- Импорт и экспорт профилей оптимизации в JSON.
- Экспорт характеристик ПК в TXT и JSON.
- Единая группа «Приложения» с подразделами установки, удаления и Microsoft Store.

### Улучшения
- Тяжёлые страницы загружаются при первом открытии.
- Бета-сборки по умолчанию выбирают beta-канал обновлений при первом запуске.
- Release workflow выполняет restore, Release build, тесты, публикацию, проверку установщика и запуск приложения.
- Обновлён интерфейс в направлении Windows 11 Fluent Design.

### Безопасность и ограничения
- Диагностика остаётся read-only.
- Загрузка профиля только выбирает твики; применение остаётся отдельным действием.
- Очистка временных файлов ограничена старыми файлами и пропускает занятые файлы и reparse points.
