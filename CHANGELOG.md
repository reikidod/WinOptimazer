# История изменений

## 0.6.0 Beta — в разработке

### Новое
- Главная панель с быстрым снимком состояния CPU, RAM, системного диска и сети.
- Диагностика Windows: свободное место, загрузка памяти, сетевое подключение, права запуска и признаки ожидающей перезагрузки.
- Локальная история действий для оптимизации, обслуживания и диагностики.
- Импорт и экспорт профилей оптимизации в JSON.
- Экспорт характеристик ПК в TXT и JSON.
- Единая группа «Приложения» с подразделами установки, удаления и Microsoft Store.

### Улучшения
- Тяжёлые страницы загружаются при первом открытии, а не все одновременно при запуске.
- Главная панель не запускает постоянный опрос датчиков; обновление выполняется по запросу.
- Бета-сборки по умолчанию выбирают beta-канал обновлений при первом запуске.
- Release workflow явно выполняет restore, Release build и тесты до публикации.
- Обновлён интерфейс в направлении Windows 11 Fluent Design.

### Безопасность и ограничения
- Диагностика работает только на чтение и не исправляет найденные проблемы автоматически.
- Загрузка профиля только выбирает твики; применение остаётся отдельным подтверждаемым действием.
- История хранится локально в профиле пользователя и не содержит содержимого личных файлов.
- Показатели Dashboard являются снимком на момент последнего обновления, а не непрерывным мониторингом.
